# LearnForCET

> 真题驱动的四六级词汇学习网站 —— 4423 个四级词 / 5513 个四六级词，每个词配历年真题原句与出处标注。

一个**纯静态前端 + Cloudflare Worker 后端**的词汇学习站：不需要构建工具，不依赖第三方 CDN 或外部字体。双击 `index.html` 就能在本机离线用；部署到 Cloudflare 后变成多用户在线站点（账户、好友、聊天）。

---

## 这个网站用来做什么

备考四六级时最大的痛点是**背了词不会用、看不出真题里怎么考**。这个项目把三件事合到一起：

1. **背大纲词**：四级 4423 词、六级全量 5513 词，分两本词书，带音标、词性、中英释义；
2. **看真实语境**：每个词自动匹配 1–2 条**历年真题原句**，标注准确出处（如 `2020年9月·第1套·阅读第46-50题`），句中该词高亮；
3. **用四种方式练**：卡片翻面 → 选择题测验 → 听音拼写 → 错题本复习，配合每日目标、连续打卡与掌握度统计。

适用人群：四六级备考学生自学；也可作为「词书 + 真题语料」类学习站的实现参考。

## 功能一览

### 学习

| 功能 | 说明 |
| --- | --- |
| **词书模式** | `LFCET4`（四级全量 4423 词）、`LFCET6`（四级 + 六级拓展共 5513 词），学习范围随时切换 |
| **单词卡** | 3D 翻转卡：正面单词 + 音标 + 发音，背面词性、中文释义、英文释义、真题例句 |
| **每日测验** | 每轮 10 道选择题，支持「英译中 / 中译英」两种题型 |
| **拼写练习** | 看中文释义拼写英文，可给首字母提示，答错自动进错题本 |
| **智能复习** | 按答错次数与掌握度优先推送薄弱词 |
| **错题本** | 答错 / 标记不认识的词自动收集，可单独复习、手动移除 |
| **掌握度追踪** | 记录每个词的对错与连对次数，连对 3 次记「已掌握」，并按词书统计进度 |
| **每日目标** | 5–100 次可设（点首页进度环或个人中心调整），环形成度实时更新 |
| **连续打卡** | 按自然日统计连续学习天数 |
| **键盘操作** | 空格翻面、`←` 不认识、`↓` 模糊、`→` 认识；测验按 1–4 选答 |

### 查词与翻译

- **查词**：先在本站 5513 词语料里秒查（词条 + 音标 + 释义 + 真题例句 + 发音），结果按「完全匹配 → 前缀 → 包含」排序；
- **权威词典跳转**：词库没有的词，一键跳必应 / 有道 / 剑桥 / 韦氏 / 朗文 / 谷歌翻译；
- **翻译**：粘贴任意文本，选方向（→中文 / →英文），一键带文本打开 Google 翻译或 DeepL。

### 账户与社交（部署到 Cloudflare 后启用）

- **注册 / 登录**：只需用户名 + 密码（≥6 位），无需手机号或邮箱；
- **个人中心**：头像（浏览器端裁剪压缩为 128×128）、昵称、签名、地址（省份/城市级联选择）、修改密码；
- **好友**：按用户名搜索、发送申请、接受/拒绝、删除；
- **聊天**：一对一消息，3 秒轮询，未读小圆点提示；
- **账户菜单**：右上角头像下拉 —— 个人中心 / 切换账户 / 退出登录。

### 界面

- **Macaron Glass 设计语言**：白→浅蓝渐变纸面、通透亚克力玻璃卡片、低饱和马卡龙配色（浅蓝 / 奶白 / 淡橙 / 浅绿）、柔和投影与充足留白；
- **果冻字母装饰**：首页与登录页的 A / B / C 立体字母（CSS 分层渐变 + 模糊柔影模拟 C4D 通透材质），配小圆球、细线条、轻薄书页；
- **深色模式**：一套独立配色（深蓝灰玻璃 + 发光字母），不是简单反色；
- **图标**：全部内联 SVG 线性图标，零 emoji；
- **响应式**：手机端单列布局，窄屏自动收起装饰层。

## 使用方法

### 方式一：本机直接用（最简单）

1. 下载本仓库，双击 `index.html`；
2. 首次进入点「注册」，自定义用户名和密码（≥6 位，无需验证）；
3. 开始学习。账户与进度保存在浏览器 localStorage，**换浏览器或换访问方式（双击文件 vs 本地服务器）需重新注册**；好友与个人中心等在线功能会自动隐藏。

> 也可用本地服务器打开（避免个别浏览器对 `file://` 的限制）：
> ```bash
> python -m http.server 8000
> # 浏览器访问 http://localhost:8000
> ```

### 方式二：部署到 Cloudflare（多用户在线版）

部署后任意设备访问同一网址，账户、头像、好友、聊天都存服务器。

**A. 网页控制台部署（不用命令行）**

1. 打开 [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers 和 Pages** → 创建 → **Pages** → **上传资产**，项目名如 `learnforcet`；
2. 把仓库**根目录下的全部内容**（`index.html`、`css/`、`js/`、`_worker.js` 等）选中一起拖入上传区 —— ⚠️ 拖的是文件夹**里面的内容**，不要拖外层文件夹，否则首页 404；
3. **存储和数据库 → D1** → 创建数据库 `learnforcet`，进入「控制台」执行 `migrations/0001_init.sql` 的全部 SQL（建 5 张表）；
4. 回到 Pages 项目 → **设置 → 绑定 → 添加 D1 数据库**，**变量名必须填 `DB`**；
5. **创建部署**，再上传一次相同文件（绑定需新部署才生效）；
6. 访问 `https://<项目名>.pages.dev`，打开 `/api/health` 应返回 `{"ok":true,...}`，注册账号即可多用户使用。

> 关键点：控制台上传**不会**执行 `functions/` 目录，所以根目录必须带 `_worker.js`（Pages 高级模式）才有后端。

**B. 命令行部署（wrangler）**

```bash
npm install -g wrangler
wrangler login
wrangler d1 create learnforcet          # 把输出的 database_id 填进 wrangler.toml
wrangler d1 execute DB --remote --file=migrations/0001_init.sql
wrangler deploy
```

详见 [DEPLOY.md](DEPLOY.md)（命令行）与 [PAGES-DEPLOY.md](PAGES-DEPLOY.md)（网页控制台，含排错表）。

│   ├── words-1.js             # 四级词库 4423 词（生成产物）

│   ├── api.js                 # 后端 API 客户端（LFAPI）
│   └── app.js                 # 应用主逻辑：视图渲染、学习流程、账户、查词、好友
├── worker/index.js            # Cloudflare Worker 后端（PBKDF2 + 会话 + D1）
├── _worker.js                 # 同一份后端副本（Pages 控制台上传用高级模式入口）
├── functions/api/[[path]].js  # Pages Functions 入口（Git / wrangler 部署时生效）
├── migrations/0001_init.sql   # D1 建表：users / sessions / friends / messages
├── wrangler.toml              # Worker 部署配置（静态资源 + D1 绑定）
├── tools/                     # 数据管线（Python，离线跑一次即可）
│   ├── extract_vocab.py       # 从词汇 PDF 抽取词条
│   ├── extract_exams.py       # 从真题 PDF 抽取句子并识别年份/套数/题型/题号
│   ├── build_data.py          # 合并词条与真题例句，输出 js/words-*.js
│   └── hand_words.json        # 少量人工校订词条
├── DESIGN.md                  # 设计系统说明（配色 token / 材质 / 无障碍）
├── DEPLOY.md                  # 命令行部署指南
└── PAGES-DEPLOY.md            # 网页控制台部署指南

## 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 前端 | 原生 HTML / CSS / JS（无框架、无构建） | 直接打开文件即可运行，按视图渲染 |
| 后端 | Cloudflare Workers | 单文件路由，零依赖 |
| 数据库 | Cloudflare D1（SQLite） | 用户 / 会话 / 好友 / 消息 |
| 认证 | PBKDF2-SHA256（10 万次迭代）+ 随机 salt | `HttpOnly` + `SameSite=Lax` 会话 Cookie，30 天有效期，登录限流 |
| 数据 | Python（pypdf）离线管线 | PDF → 结构化 JSON → `words-*.js` |
| 字体 | 系统字体栈 | 无 Google Fonts 等外部请求，国内访问不卡 |

## 数据说明

- **词库**：四级 4423 词、六级全量 5513 词，含音标、词性、中英释义；
- **真题例句**：从 2016–2025 年四级、六级真题 PDF 中抽取约 1 万条句子，按「年份 · 套数 · 题型题号」标注来源，通过词形还原（复数/时态/派生）匹配到对应单词；
- 例句覆盖率约：四级 80%、六级 62%（其余词在已收录年份的真题中未出现）；
- ⚠️ 真题文本版权归原出版方所有，本仓库中的例句仅用于学习研究，请勿商用。

## 已知限制

- 学习进度按「浏览器 + 账户」存 localStorage，**尚未做跨设备同步**（账户资料、好友、聊天在服务器）；
- 本机模式下好友 / 聊天 / 头像不可用（需要服务器）；
- 词库与例句是离线构建产物，更新需重跑 `tools/` 脚本，并递增 `index.html` 里的 `?v=` 版本号刷新浏览器缓存。
